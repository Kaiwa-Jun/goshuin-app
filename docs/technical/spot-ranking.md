# スポットランク基準

## 概要

マップ画面でのスポット表示をズームレベルに応じて制御するため、各スポットに rank（1〜5）を付与する。ランクが高いスポットは広域表示でも表示され、ランクが低いスポットはズームインしないと表示されない。

## ランクの目的

- マップの視認性を確保（広域でピンが密集しない）
- パフォーマンス維持（同時表示マーカー数を制限）
- ユーザーにとって重要なスポットを優先的に見せる

## ランク基準

御朱印アプリの特性上、**御朱印集めの人気度**を最も重視する。

### rank 5（常に表示）

**基準**: 御朱印人気ランキング TOP10 相当 + 全国的知名度

判定方法:

- ホトカミ（hotokami.jp）の都道府県別御朱印ランキングで上位10位以内
- 全国的に知られる神社仏閣（一宮、国宝、日本三大〇〇等）

### rank 4（やや広域から表示）

**基準**: 御朱印人気ランキング 11〜20位相当 + 地域を代表する人気スポット

判定方法:

- ホトカミの御朱印ランキング 11〜20位程度
- 限定御朱印やアート御朱印で知られるスポット
- 観光ガイドで必ず紹介されるレベル

### rank 3（中域から表示）

**基準**: 地域の代表格、観光名所、巡礼の主要札所

判定方法:

- 市区町村の代表的な神社仏閣
- 観光サイトに掲載されるレベル
- 巡礼の中でも特に重要な札所（日本三大不動尊等）
- ホトカミでの投稿数がそこそこある

### rank 2（詳細表示で表示）

**基準**: 巡礼札所、地域で知られるスポット

判定方法:

- いずれかの巡礼コースに含まれる札所
- 御朱印がいただけることが確認されているスポット
- ホトカミでの投稿数は少ないが存在する

### rank 1（最大ズームで表示）

**基準**: 小規模な札所、限定的に知られるスポット

判定方法:

- 小規模な巡礼の札所（仙台三十三観音等の個別寺院）
- 御朱印対応が不明確なスポット
- 一般的な知名度が低い

## 情報源

ランク判定に使用する情報源（優先順位順）:

1. **ホトカミ（hotokami.jp）** — 御朱印人気ランキング、投稿数
2. **Omairi（omairi.club）** — 人気ランキング
3. **Wikipedia** — 社格、文化財指定、歴史的重要度
4. **pilgrimage_spots テーブル** — 巡礼参加数（自動算出可能）
5. **各神社仏閣の公式サイト** — 御朱印対応の確認

## マップ表示の閾値

| ズームレベル（latitudeDelta） | 表示する rank |
| ----------------------------- | ------------- |
| > 0.5（県全体）               | rank 5 のみ   |
| > 0.1（広域）                 | rank 4 以上   |
| > 0.02（市街地）              | rank 3 以上   |
| > 0.005（近隣）               | rank 2 以上   |
| <= 0.005（最大ズーム）        | 全て表示      |

## 新しい県のスポットを追加する際の手順

1. ホトカミで対象県の御朱印ランキングを確認
2. TOP10 → rank 5、11〜20位 → rank 4 を仮設定
3. Wikipedia で社格・文化財を確認し、漏れがあれば補正
4. 巡礼札所を rank 2 に設定
5. 残りの小規模スポットを rank 1 に設定
6. DB に反映
