### 説明文（4000文字以内）

```
「集めるたび、地図があなたの旅になる。」

御朱印さんぽは、参拝の記録と御朱印の写真を地図上に残せる、シンプルで美しい御朱印管理アプリです。複雑な操作は一切不要。写真を撮って、スポットを選ぶだけで、あなたの御朱印コレクションがどんどん豊かになっていきます。


■ 主な特徴

◎ 写真1枚でかんたん記録
参拝先で御朱印の写真を撮るだけ。現在地周辺の神社・寺院が自動で候補表示され、タップひとつで記録が完了します。メモや訪問日も残せるので、あとから見返すのも楽しみに。

◎ 地図で振り返る、旅の軌跡
訪れたスポットは地図上にピンで表示。御朱印を集めるほど、あなただけの「参拝マップ」が育っていきます。赤いピンは神社、紫のピンは寺院。ひと目で巡礼の歩みが分かります。

◎ ギャラリーで一覧表示
記録した御朱印はギャラリーで一覧表示。日付順・スポット順で並び替えができ、コレクションとして眺めるだけでも満足感があります。

◎ コレクション統計とバッジ
総訪問箇所数、地域別の訪問数、巡礼チャレンジの進捗などを一覧で確認可能。達成バッジを集めて、次の参拝への楽しみを広げましょう。

◎ 全国1,000件以上のスポットを収録
神社・寺院のマスタデータを全国から収録。知らなかった近隣のスポットも地図から発見できます。掲載されていない場合はユーザー追加にも対応。


■ こんな方におすすめ

・御朱印集めを始めたばかりで、記録の方法に迷っている方
・参拝記録を紙の御朱印帳だけでなくデジタルにも残したい方
・旅行や散歩の途中で立ち寄った神社仏閣を地図で振り返りたい方
・ゲーム感覚で御朱印集めを楽しみたい方
```

### 1.2.0 の4枚（2026-09-26 オーナー承認）

**画像は `~/Desktop/goshuin-store-1.2-draft/01.png`〜`04.png`（1320×2868）。Git には入れない**（本アカウントの記録が写るため。1.1.0 の `~/Desktop/goshuin-store-1.1/` と同じ扱い）。
1.2.0 を審査に出すときに App Store Connect で差し替える。

| #   | 画面                                           | 見出し                               |
| --- | ---------------------------------------------- | ------------------------------------ |
| 1   | 地図タブ（京都・八坂神社のシートを閉じた状態） | 近くの寺社が、すぐ見つかる。         |
| 2   | 保存直後（明治神宮）                           | 写真を1枚。それだけ。                |
| 3   | あゆみの日本地図                               | 集めるたび、地図があなたの旅になる。 |
| 4   | 御朱印帳（櫻岡大神宮）                         | 集めた御朱印は、一冊になる。         |

決めたこと:

- **4枚とも縦**（斜めはやめた）。端末は大きく置き、下の端をはみ出させる。枠・角丸・見出しの位置と大きさは4枚で同じ
- 写す御朱印は**墨書きと朱印だけのもの**（切り絵・イラスト入りは避ける）
- 3枚目の日本地図は、本物の記録だと色のつく県が少ないので、**集計の数字だけを見本（25都道府県・91枚）に差し替えて**撮った。画面の描き方は本物のまま。本番の DB には書いていない
- 1枚目は、ピンを6本以上入れるために地図の最初のズームだけ一段引いて撮った
- 1.2.0 の新機能（もう少し・寺社の追加）の画像は入れない

撮り方（次回もこの手順で）:

1. シミュレータ `shots-16promax`（iPhone 16 Pro Max 相当・1320×2868）に入っている preview-simulator のアプリの `main.jsbundle` を、今のコードで書き出したものに差し替える
   （`npx expo export:embed --platform ios --dev false --entry-file node_modules/expo/AppEntry.js --bundle-output <out>/main.jsbundle --assets-dest <out>`）。ネイティブが変わっていなければ EAS のビルド枠を使わずに撮れる
2. 見本の数字やズームは、書き出す前に手元で一時的に書き換え、書き出したらすぐ `git checkout` で戻す（コミットしない）
3. 画面の操作は Maestro（`tapOn: point` とスワイプ）、撮影は `xcrun simctl io booted screenshot`
4. 保存直後の画面は、実際に1件記録して撮り、撮ったら削除する（枚数が一時的に1増える）
5. 枠と見出しは PIL で合成（背景の朱 `#C2342B`→`#AB2E26`、見出しはヒラギノ角ゴ W8）

### 撮影の手順

**前提**: 30件ほど記録のあるアカウント。空だと1枚目が灰色一色で成立しない。

**本アカウントで撮る**（2026-09-22 ユーザー判断）。実際の参拝先がストアに載ることは了承済み。
捨てアカウントは使わない — 空だと日本地図も蛇腹も絵にならないため。
⚠️ Apple が要求する**アカウント削除の画面録画**のほうは、本アカウントだと記録が消えるので
**捨てアカウント（Google）を使うこと**。用途で使い分ける。

1. **1枚目** — あゆみタブを開く。**塗りが終わるまで待つ**（約2.2秒）。上の「◯◯ / 47 都道府県」と
   枚数が出ている状態で撮る
2. **2枚目** — 記録画面から1枚保存し、完了画面でピンが刺さり切ってから撮る。
   ⚠️ 撮影用に1件増えるので、**1枚目を先に撮る**（県の数が変わる）
3. **3枚目** — 御朱印帳タブ →「蛇腹」に切り替え。**開いた位置（最後の御朱印）が正面**なのでそのまま撮る。
   左右のページが覗いて見えているほうが「本」らしい
4. **4枚目** — 地図タブ。ピンが複数見える位置まで引く

**文言のオーバーレイは後から載せる**（Figma / Canva）。撮るのは素の画面だけ。

### X 用の動画
