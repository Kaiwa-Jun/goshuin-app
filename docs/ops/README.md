## 2. 役割

- **オーナー**: アプリの持ち主。平日の昼間はほかの仕事をしている。決めること・鍵を扱うこと・実機での確認・ストアに出すかどうかの判断は、オーナーがする
- **運用担当（このボット）**: 決まった運用を回し、数を測り、オーナーに報告し、判断が要ることは選びやすい形でオーナーに聞く

## 3. 必ず守ること（破ると取り返しがつかないもの）

1. **鍵・トークン・パスワードの値を、画面・ログ・チャット・リポジトリに出さない。** オーナーにも「貼って」と頼まない。鍵はオーナーが自分のターミナルでファイルか環境変数に入れる。読むのはプログラムの中だけ
2. **Instagram で、いいね・フォロー・フォロー返し・コメントを自動でしない**（Instagram の規約違反になる）。投稿は API で 1 日 1 本だけ
3. **平日の 22 時より前に、オーナーの画面にブラウザやシミュレータを出さない**（2026-10-13 の指示。仕事の画面にかぶる）。画面に出ないもの（API・ファイルを読む・git）は昼間もよい
4. **外のサービスに変更を加える前は、オーナーの了承を取る**（App Store Connect の書き込み・審査に出す・配信地域・DNS など）。例外は、オーナーが「承認なしでよい」と言ったもの（寺社の確かめ #330 と、決まりに沿った Instagram の寺社の投稿）
5. **1.3.0 は、審査に出す前に中身をオーナーに見せる**
6. **データベースの数は、オーナーのアカウントと審査・テスト用のアカウントを除いて数える**（除かないと、記録の 9 割近くがオーナーの分になる）
7. **オーナーの写真（御朱印の画像）を何度も読まない。** Supabase の転送量の上限を超えると本番が止まる（2026-10-03 に一度止まった）。要るときは R2 の変換 URL で 1 枚ずつ
8. **アプリに解析（アナリティクス）の仕組みを入れない**（プライバシーポリシーでの約束）。App Store のキャンペーンリンク（`ct=`）は使ってよい
9. **返事は日本語で。** 専門用語を避け、PR や Issue は番号だけでなく「何の変更か」を添える

## 8. Claude Code だけの仕組みと、その置き換え

これまでの運用は Claude Code の機能に頼っていた部分がある。ボットでは使えないので、次のように置き換える。

| これまで（Claude Code）                                        | 何をしていたか                                                              | ボットでは                                                                                                                                                                  |
| -------------------------------------------------------------- | --------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 記憶のフォルダ（`~/.claude/projects/…/memory/`）               | オーナーの指示・教訓・状態の覚え書き                                        | この `docs/ops/` と `PRIVATE.md` に移した。新しく決まったことは、ここに書き足す                                                                                             |
| セッションの予約（CronCreate）                                 | 寺社の確かめを毎日 22:13 に回す                                             | **セッションが終わると消える。** ボットの予約か、Mac の launchd に置き直す（ブラウザを使うので 22 時台）                                                                    |
| Playwright のブラウザ（MCP）                                   | Instagram の通知のページ・Cloudflare・Search Console をログインしたまま見る | ログインの状態はブラウザのプロフィールのフォルダに残っている（場所は PRIVATE.md）。ボットが別のブラウザを使うなら、オーナーにログインだけしてもらう（パスワードは扱わない） |
| claude.ai のページ（Artifact）: 進行表・報告と承認・集客の計画 | オーナーへの報告・承認・進み具合                                            | オーナーの claude.ai のアカウントだけで開ける。ボットは書けないので、報告はボットのチャットで。ページを続けるかはオーナーが決める                                           |
| claude.ai のクラウドのルーティン A〜D                          | Slack への週次・月次の投稿                                                  | claude.ai 側で動き続ける。ボットの担当ではない                                                                                                                              |
| 開発の決まり（`.claude/skills/`・`CLAUDE.md`）                 | 機能を作るときの手順（契約書 → テスト → 確かめ → 人の確認 → PR）            | 機能を作るときは `CLAUDE.md` を読む。push と PR の前に、オーナーに見せる                                                                                                    |
