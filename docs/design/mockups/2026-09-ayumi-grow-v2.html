役割の分け方

  • もう少し（上）＝「あと少し」の一覧。地方・月参り・印から近いものを最大3つ。押すと、地方は地図へ・月参りは寺社へ・印は印の欄へ。近いものが無ければカードごと出さない
  • 地図＝その場所を見せる。一番近い地方の残りだけ点線（v1 の吹き出しは「もう少し」と重複するので外した）
  • 地方の帯＝地図の下。1県1マス、塗った色は地図と同じ。近い順に並べ、一番近い地方だけ朱。残りのマスも点線でそろえる

「近い」の決め方（案）

  • 地方: 残り県数が 1〜3（残り4以上は出さない＝急かさない）
  • 月参り: 満願まで 1〜3ヶ月、かつ今月まだ参拝していない
  • 印: 次の印まで 残り2割以内（例: 五十なら 40箇所から）
  • 並びは「あと」の小さい順。同じなら 地方 → 月参り → 印

制覇したとき

  • 帯の右が「制覇」になり、地方名の横に小さな朱の丸。お祝いの演出は、その地方の最後の1県を記録した完了画面で出す（あゆみでは静かに）

決めたいこと

  • 言い回し: 「制覇」でいいか（「満願」「結願」は仏教・巡礼の言葉なので地方には使わない案）
  • 地方の分け方: いまの6地方（北海道・東北 / 関東 / 中部 / 近畿 / 中国・四国 / 九州・沖縄）でいいか。8地方（北海道・東北を分ける等）にすると「あと1県」が出やすい
