# 要件: 保存した直後を作り込む（UX メモ 提案②）

デザイン: **`docs/design/mockups/2026-09-ayumi-v3-motion.html`**（「保存直後」タブ。動きまで触れる）
旧デザイン: `2026-09-record-complete-v1.html`（静止画の版）
出典: UX メモ https://claude.ai/artifact/HdRsemF7phLZVYPG1CjNu6
ステータス: **確定（2026-09-21 ユーザー承認）。実装済み**

## 1. UX メモの前提を1つ訂正する

メモの「いま」の絵は **`保存中…` のスピナーだけ**になっているが、**実物は違う**。
`RecordCompleteScreen.tsx` は既に、全面オレンジのグラデーション・紙吹雪（`ConfettiEffect`）・
チェックマーク（`CheckmarkAnimation`）・バッジ演出（`BadgeAnimation`）まで持っている。

**問題は「祝っていない」ことではなく、祝い方が汎用的なこと。**
チェックマークと紙吹雪は何のアプリでも出せる。**このアプリにしか出せないのは、いま授かった御朱印そのものと、色づく県**。

## 2. いまの実装（正確に）

| 要素       | 実装                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| 背景       | `LinearGradient` primary[400] → primary[500]                             |
| 演出       | `ConfettiEffect`（紙吹雪）+ `CheckmarkAnimation` 80px                    |
| 見出し     | 「登録完了！」                                                           |
| 御朱印     | `stampImageUrl` があれば表示。無ければ写真アイコンのプレースホルダ       |
| 枚数       | **まとめ登録が2枚以上のときだけ**「N枚」（通算ではなくこの記録の枚数）   |
| スポット名 | `spotName`                                                               |
| 件数       | 「N箇所目の御朱印！」（`visitCount` = 訪問した**箇所数**）               |

## 4. 地図の動き

**全国 → その県へ寄る、1つの動き**にする。

| 時刻  | 起きること                                                             |
| ----- | ---------------------------------------------------------------------- |
| 0.00s | 自分の色づいた**全国**の地図が見えている（その県はまだ塗られていない） |
| 0.56s | カメラがその県へ寄りはじめる（1.1秒・`Easing.out(cubic)`）             |
| 1.66s | 寄り終わり。**雫型のピンが落ちて**（0.52秒）、**その県が色づく**       |
| 同時  | 通算の枚数が 33 → 34 に数え上がる                                      |

- **いきなり地方だけを出さない。** 「自分の日本が埋まっていく」という一番効く感覚を、
  一番受け取りやすい瞬間に捨てることになる。先に全国を見せてから寄る
- 寄りの強さは「地方くらい」（県の5.5倍の幅）。①のタップ時の寄りと**同じ計算**を使う
- **ピンは地図タブのピンと同じ雫型**（`scripts/generate-map-pins.py` の実寸）。色は記録した
  寺社の種別に合わせる（神社=朱 / 寺=紫）。落ちてきたピンが、地図で見るのと同じピンになる
- ピンは地図の縮尺で伸び縮みさせない。寄せたあとの位置に、一定の大きさで置く
- `AccessibilityInfo.isReduceMotionEnabled` が真なら、**寄り終わった状態をすぐ出す**

## 5. 分岐（全部出るわけではない）

| 条件                           | 表示                                                                                                                                                       |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| その県が2回目以降              | チップを出さない。地図は**記録する前の濃さから濃くなる**（朱で光らせない。理由は `docs/issues/issue-209-ayumi-japan-map.md` の「朱の点滅を入れない理由」） |
| まとめて複数枚登録             | 御朱印は先頭の1枚。大きい数字は通算の最後の枚数（例: 3枚なら「36枚目」）                                                                                   |
| 写真がない                     | いまのプレースホルダを白カードの中でそのまま使う                                                                                                           |
| `countUnavailable`（通信失敗） | **大きい数字と地図とチップを出さない**。御朱印・寺社名・日付だけ出し、注記を1行添える。Issue #133 の原則（嘘の数字を祝わない）どおり                       |
| 県が分からない                 | 地図を出さない（寺社に県が入っていない場合）                                                                                                               |
| バッジ獲得                     | `BadgeAnimation` はそのまま。御朱印カードの**後**に出す                                                                                                    |

## 6. データ

いま `RecordComplete` に渡っていないものが3つある。**すべて `RecordScreen.save()` から渡す**（完了画面では取りに行かない。画面が出てから数字が動くのを避ける）。

| 要るもの                        | いまの状態                       | 対応                                                                                                                                                                    |
| ------------------------------- | -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 通算の枚数                      | ❌ `stampCount` はこの記録の枚数 | `fetchCollectionStats` の `stampCount` + 今回の枚数                                                                                                                     |
| 記録した県                      | ❌ 渡っていない                  | `form.selectedSpot.prefecture` をそのまま渡す                                                                                                                           |
| その県が初めてか / 県ごとの枚数 | ❌ 渡っていない                  | **保存する前に `fetchRegionStats` を呼ぶ**。完了画面が開いてから取りに行くと、祝っている最中に地図の色が後から変わる。失敗しても記録は止めない（Issue #133 と同じ扱い） |
| 参拝日                          | ❌ 渡っていない                  | `YYYY-MM-DD` のまま渡す。`new Date()` を挟むと Issue #204 と同じ1日ずれを踏む                                                                                           |

## 7. やらないこと

- **紙吹雪（`ConfettiEffect`）とチェックマーク（`CheckmarkAnimation`）は外した**（2026-09-21 承認）。
  あれは何のアプリでも出せる演出で、このアプリにしか出せないのは御朱印と色づく県。
  「登録完了！」の見出しも消した（御朱印が出ていれば完了は伝わる）
- シェアボタン・SNS 投稿導線
- 「連続◯日」「今日のノルマ」の類い

## 8. アクセシビリティ

- ミニ地図に `accessibilityLabel`「東京都がいま色づきました。47都道府県のうち13県」
- 「はじめて」チップは色だけで意味を持たせない（🗾 と文言の両方）
- `prefers-reduced-motion` 相当（RN は `AccessibilityInfo.isReduceMotionEnabled`）のとき、点灯のアニメーションを止めて最終状態だけ出す

## 9. 決まったこと（2026-09-21）

1. **紙吹雪とチェックマークは外す**
2. 大きい数字は **「34枚目」（通算の枚数）**。まとめ登録のときは「この日 3枚」を別に添える
3. 地図は**全国から寄る**。いきなり地方だけは出さない
4. ピンは**地図タブと同じ雫型**で、色は寺社の種別に合わせる
