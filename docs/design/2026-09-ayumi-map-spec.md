## 0. v2 から何が変わったか（実機のフィードバック）

タイル版を実機で見て、3つ差し戻った。

| 指摘                                                           | 決定                                                     |
| -------------------------------------------------------------- | -------------------------------------------------------- |
| 同じ大きさの正方形だと**日本列島の再現度が低い**               | **本物の県境**で描く。`react-native-svg` を入れる        |
| 濃さ＝量なのに「いちばん新しい」も色で出すのは**直感に反する** | **「いちばん新しい」を地図から外す**。色の意味は枚数だけ |
| 凡例が「いちばん新しい／訪問済み／まだ」になっている           | 凡例は**枚数の段**にする                                 |
| 県のシートが**行き止まり**（他へ行けない・閉じられない）       | **シートをやめて「画面」にする**                         |
| 御朱印のビューアの**レイアウトが見切れる**                     | 同上。画面にすれば全画面ビューアが普通に開く             |

**「いちばん新しい」を地図から外した理由**: 地図の仕事は「日本がどれだけ埋まったか」という
ゆっくり育つ絵で、「いちばん新しい」は参拝のたびに動く一瞬の情報。時間の性質が違うものを
同じ絵に載せていた。すぐ下の「最近の参拝」が寺社名と日付付きで同じことを答えているので、
地図に載せても情報は増えないまま、色の意味が2つになり、凡例が1行増え、読み上げが増え、
色覚多様性の問題まで発生していた。**「いちばん新しい」が効くのは保存直後の一瞬だけ**なので、
出来事は出来事の画面（提案②）で見せる。

## 1. なぜやるか

アプリのコンセプトは「集めるたび、地図があなたの旅になる。」なのに、**あゆみ画面に地図がない**。
いま出ているのは「12箇所 / 34枚」という集計表で、これは達成感で終わる。
**白いままの四国は「行かなきゃ」になる。** 素材（行った場所・日付）はもう持っていて、見せ方だけが足りていない。

## 2. 決めたこと（2026-09-21・ユーザー確認済み）

| 論点         | 決定                                                                                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 構成         | **地図カードが集計カードと地域別セクションの両方を兼ねる**。オレンジの集計カードは廃止し、数字は地図カードの上部に載せる。「地域別」の棒グラフは畳む |
| 地図の描き方 | **本物の県境**（`react-native-svg`）。タイルのカルトグラムは不採用                                                                                   |
| 最新の県     | **地図には出さない**。色の意味は枚数だけ。凡例も枚数の段にする                                                                                       |
| 県名ラベル   | **出さない**（本物の県境なら形で分かる。正式名はタップした先の画面が出す）                                                                           |
| タップ挙動   | **その県の御朱印一覧を出す。シートではなく「画面」**                                                                                                 |
| 濃さの基準   | **御朱印の枚数**（箇所数ではない）。上部の「34枚」と数え方を揃える                                                                                   |
| 県の達成率   | 「28/35」は**県別画面**に移す。あゆみのトップからは畳む                                                                                              |

## 3. 画面構成

| いま                                    | あと                                               |
| --------------------------------------- | -------------------------------------------------- |
| ① オレンジの集計カード（12箇所 / 34枚） | ① **都道府県タイルマップのカード**（数字はこの中） |

## 4. 日本地図

### 4-1. 県境のデータ

| 項目       | 値                                                                                         |
| ---------- | ------------------------------------------------------------------------------------------ |
| 出どころ   | **Natural Earth**（`ne_10m_admin_1_states_provinces`）。**パブリックドメイン**（ODC PDDL） |
| 変換       | `docs/design/mockups/build-japan-paths.py`（メルカトル → Douglas-Peucker → SVG パス）      |
| 成果物     | `docs/design/mockups/japan-paths.json`。47県 / 3704点 / **43KB**                           |
| 県名のキー | ISO 3166-2:JP から引いた正式名（`regionBlocks.ts` と同じ表記）                             |
| viewBox    | `0 0 1000 1132`                                                                            |

- **Wikimedia の県地図は使わない**。CC BY-SA が多く、アプリに同梱するには向かない
- Natural Earth の `name_local` は**静岡県が null** なので、現地名ではなく ISO コードから引く
- **沖縄は左下の海へ別枠**（本島まわりのみ・2.2倍）。与那国から南大東まで入れると横に1000km以上広がって枠に収まらない。日本の地図の慣習どおり
- 本島の2%より小さい島は落とす（点数の大半がそこに消える）

### 4-2. 見た目

| 項目       | 値                                                                                      |
| ---------- | --------------------------------------------------------------------------------------- |
| 県の塗り   | 未訪問 `#E3E4E8` / 1〜2枚 `primary[300]` / 3〜5枚 `primary[500]` / 6枚〜 `primary[700]` |
| 県境       | 白 2（viewBox 単位）                                                                    |
| 県名ラベル | **出さない**                                                                            |
| カード上部 | 左「**12**」34px/900 +「/ 47 都道府県」13px、右「**34**枚」                             |
| 凡例       | `まだ 35` / `1〜2枚` / `3〜5枚` / `6枚〜` の4つ。11px・罫線で区切る                     |

**色の意味は「枚数」ひとつだけ**。他の情報を色に載せない。

### 4-3. 動き（あゆみを開いたとき）

**県が南から北へ、1県ずつ塗られていく**（1県 90ms・全体で約1.2秒）。上部の数字も同時に増える。

- 狙いは「旅が進む」感じ。全部を一度に出すと集計表に戻ってしまう
- `AccessibilityInfo.isReduceMotionEnabled` が真なら**最終状態を即座に出す**
- 画面を離れて戻るたびに毎回再生はしない（うるさい）。**フォーカスのたびではなく、データが変わったときだけ**

### 4-4. 空の状態

- **0件**: 47県すべて灰色。上部は「0 / 47 都道府県」。**空の地図そのものが予告**なので、イラストや説明文で埋めない
- **ゲスト**: いまの `collection-guest-empty-state` のまま（地図は出さない）

## 5. 県をタップしたとき — シートではなく「画面」

`CollectionStack` に画面を1つ足す（`PrefectureDetail`）。**シートにしない**。
モーダルの中に全画面のビューアを入れ子にすると、ビューアが画面ではなくシートを基準に
レイアウトを組んでしまい、ボタンが見切れる。行き止まりにもなる（実機で両方出た）。

| 要素       | 仕様                                                                                 |
| ---------- | ------------------------------------------------------------------------------------ |
| ヘッダー   | 戻るボタン + 正式名（「東京都」）                                                    |
| 県の形     | その県だけを 74px で描く。**いちばん大きい島だけ**（離島を入れると本体が豆粒になる） |
| 集計       | 「**16枚**」と「3 / 20箇所」                                                         |
| 御朱印     | 3列のグリッド（縦長 3:4）。`prefecture-stamp-{id}`                                   |
| タップ     | 既存の `ImageGalleryModal` が**普通に全画面で**開く（入れ子にしない）                |
| 未訪問の県 | 「まだ御朱印がありません」+「この県の寺社を見る」→ 地図タブをその県へ寄せる          |

## 6. データ

既存の `fetchRegionStats`（`src/services/collection.ts`）に**県ごとの枚数**を足すだけ。

| 要るもの           | いまの状態                                              | 対応                                         |
| ------------------ | ------------------------------------------------------- | -------------------------------------------- |
| 県ごとの訪問数     | ✅ `visitedCount`（`spot_id` で重複排除した**箇所数**） | そのまま                                     |
| 県ごとの**枚数**   | ❌ 返していない                                         | 同じクエリの行数を県ごとに数えるだけで取れる |
| その県の寺社の総数 | ✅ `totalCount`                                         | 県別画面の「3 / 20箇所」に使う               |

⚠️ **`latestVisitedAt` / `latestCreatedAt` / `latestPrefecture` は使わなくなった**（地図から
「いちばん新しい」を外したため）。v2 の実装で足したものなので、**消す**。使われない値を
返し続けると、次に読む人が「どこかで使っているはず」と探すことになる。

## 7. アクセシビリティ

- 地図全体に `accessibilityLabel`「47都道府県のうち12県」
- 県ごとに「東京都、6枚」／未訪問は「東京都、まだ」。`accessibilityRole="button"`
- **地図のコンテナに `accessible` を付けない**。付けると47県が1要素にまとめられ、県ごとの読み上げが消える
- **色だけで段を区別させない**。読み上げが枚数を持つ
- 4段（未訪問 / 300 / 500 / 700）の知覚距離は `theme.test.ts` と同じやり方でテストする。**色に載せる意味が1つになったので、リングのような補いは要らなくなった**
- 地図タブの未訪問ピンは `#FB923C`（primary[400]）で、1〜2枚の `#FDBA74`（primary[300]）とは別の段。実機で並べて紛れないか見る
- 塗り広がりの動きは `AccessibilityInfo.isReduceMotionEnabled` で止め、最終状態を即座に出す

## 8. やらないこと

- 他人との比較・ランキング・シェアボタン
- 「何県制覇しました」の煽り。**塗られていない県を責めない**
- 地図に「いちばん新しい」を出すこと（§0 の理由）
- 県名ラベルを県の上に出すこと。**本物の県境なら形で分かる**し、47個の文字は密になる

## 9. 依存パッケージの追加

**`react-native-svg` を1つだけ入れる。** これまで避けていたが、本物の県境を描くには要る。

- Reanimated / Lottie / Rive は**入れない**。塗り広がり・ピンの落下・カメラの寄りは
  RN 標準の `Animated`（`useNativeDriver`）で作れる
- **dev build の焼き直しが1回要る**（`eas build --profile development --platform ios`・15〜20分）

## 10. 実装時に決めてよいもの

- 「最近の参拝」の件数。試作は3件。**3件で始める**（増やすのは後からでも効く）
