御朱印の参拝記録アプリ「御朱印さんぽ」の「あゆみ」タブの画面を作ってください。UIの文字はすべて日本語です。

## このアプリ

神社・寺で授かる御朱印の参拝記録を地図に貯めるiOSアプリ。コンセプトは「集めるたび、地図があなたの旅になる。」
SNS機能なし・広告なし・他人と比べさせない、静かで美しい記録アプリ。ユーザーは20〜30代の女性が中心。

## いまの実装（これを置き換える）

画面上部にオレンジのグラデーションカードがあり「これまでの達成 / 12 箇所 / 34 御朱印（枚）」と数字だけを出している。
その下に「獲得バッジ」「巡礼チャレンジ」「地域別」。コンセプトに地図と書いてあるのに、この画面に地図がない。

## 作ってほしい画面（上から順に）

1. ヘッダー「あゆみ」（左寄せ・太字28px）
2. **日本地図の塗り絵カード**（この画面の主役）
   - 白いカード、角丸16、薄い影、内側に余白12
   - カード上部の行: 左に「12」を大きく（34px・900）、続けて小さく「/ 47 都道府県」、右端に「34枚」
   - **47都道府県を正方形のタイルで並べたグリッド型カルトグラム**（地理的な輪郭の日本地図ではなく、11列×14行のグリッドに小さな角丸の四角を日本列島の配置で置いたもの）。北海道は右上、沖縄は左下
   - タイルの色: 未訪問 `#E3E4E8` / 1〜2枚 `#FDBA74` / 3〜5枚 `#f27f0d` / 6枚以上 `#C2410C` / いちばん新しく参拝した1県だけ朱色 `#DC2626`
   - 12県だけが色付き、残り35県は未訪問の灰色。**白い空白が多いことが「まだ行っていない場所」として見えること**が狙い
   - カード下端に小さな凡例: ■いちばん新しい ■訪問済み ■まだ
3. **最近の参拝**（縦のタイムライン・3件）
   - 左に小さな丸（神社は `#DC2626`、寺は `#9333EA`）と縦の細い線でつなぐ
   - 「湯島天満宮 09/20」「浅草寺 09/14」「大崎八幡宮 08/31」
4. **獲得バッジ**（見出し18px・右に「すべて見る」）
   - 円形のバッジを横に5つ。獲得済み3つ（🎊 はじめての御朱印 / ⛩️ 5箇所達成 / 🏆 10箇所達成）は白い円に絵文字、未獲得2つ（🌟 / 🗾）は薄く。鍵アイコンは使わない
5. **巡礼チャレンジ**
   - 白いカード。「現在の目標」ラベル + 「挑戦中」のpillチップ、名前「仙台三十三観音」、右に「12/33」、オレンジのプログレスバー36%
6. 下タブバー4つ: 地図 / 御朱印帳 / あゆみ / 設定（**あゆみが選択中でオレンジ**）。Material Icons の explore / menu-book / timeline / settings。**中央の丸いFABは置かない**
