# 要件: 参拝の予定を組む（参拝ルート計画）

デザイン: **`docs/design/mockups/2026-09-route-plan-v1.html`**
ステータス: **試作（未承認）**
関連: 収益化の設計 `docs/product/2026-09-monetization-design.md`（予定1つは無料・何件でも/自動並べ替え/移動時間はプラス）/ memory「日々開きたくなる・愛着の仕組み」（オーナーが一番欲しい機能）

## 1. 何をするか

休日に何社か回るとき、寺社を選んで**ある日の予定**を作り、回る順番を決める。
移動は**電車＋徒歩**が中心（オーナー回答 2026-09-26）。

- 選び方は2つ: **行きたいリストから** / **地図で近くの寺社から**（両方から足せる）
- 回る順番に番号を付け、地図の上で**点線でつなぐ**
- 寺社と寺社のあいだ（区間）ごとに、**「この区間を Google マップで」**。押すとその1区間の**電車＋徒歩の道順**が Google マップで開く
  - Google マップは**電車の経路で複数の目的地を扱えない**（2026-09-26 確認）ので、まとめて渡さず区間ごとに渡す
- 区間の所要時間は**距離からの目安**（経路検索の API は使わない＝費用 0）
  - 直線距離 × 1.3 が 1.5km 以内 → 「徒歩 約N分」（分速80m）
  - それより遠い → 「電車などで移動 約N km」
- 各寺社に**受付時間**（あれば）を出す。回る順番の目安の時刻が受付の終わりを過ぎたら、朱で知らせる

## 2. 画面（試作 v1）

| #   | 画面               | 中身                                                                                                                                  |
| --- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| ①   | 予定の入口         | 地図タブの検索欄の右に「予定」。スポットのシートにも「予定に入れる」                                                                  |
| ②   | 寺社を選ぶ         | 上に地図（押すと追加）、下に「行きたい」の寺社（チェックで追加）。下に「選んだ寺社 N ・ 順番を決める」                                |
| ③   | 予定               | 日付・名前。地図に番号つきのピンと点線。下に 寺社 → 区間 → 寺社 … の縦の並び。区間に目安と「Google マップで」。並べ替えはつまんで移動 |
| ④   | 順番を自動で並べる | 近い順に並べ替える（出発地点から、最短に近い順）。**プラス**（課金をオンにするまでは誰でも使える）                                    |

## 3. 無料とプラス（収益化の設計 §8）

| 無料                                | プラス                             |
| ----------------------------------- | ---------------------------------- |
| 予定を1つ作る・見る・手で並べ替える | 予定を何件でも残す                 |
| 区間ごとに Google マップで開く      | 順番を自動で並べる・移動時間の目安 |

**課金をオンにするまでは、全部を誰でも使える**。コードには「プラスなら」の分かれ目だけ作る。

## 4. やらないこと（v1）

- アプリの中での本当の道順・乗り換え（案2。よく使われたらプラスで足す）
- 予定の共有・他人との同時編集
- 通知（前日にお知らせ など）
- 予定の寺社をまとめて記録する（その日の夜に「今日の予定の寺社を記録」は後で考える）
