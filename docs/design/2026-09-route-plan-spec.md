## 0. v1 へのオーナーの意見で決めたこと（2026-09-26）

1. **入口は下のタブ**: 地図 / **予定** / 御朱印帳 / あゆみ / 設定。予定は1社への操作ではなくアプリ全体の機能なので、地図の検索欄の横やスポットのシートには置かない（検索欄の右のフィルタとも重ならない）。フィルタを検索欄の下のバッジにする案は別の改善として後で
2. **予定タブを開くとカレンダー**。予定のある日に印。空いた日を押すとその日付で予定を組む画面へ。「＋ 予定を組む」でも入れる（日付は保存のときに）
3. **予定を組む画面は、上が地図・下がドロワー**。ピンを押すと小さなカード（名前と「＋ 予定に入れる」/「予定から外す」）。ドロワーには選んだ寺社が入っていく。空のときは「行きたいから選ぶ」の一覧。行きたいの寺社はいつもの色（ティール）で目立つ
4. **「順番を決める」で、同じ画面のままドロワーだけが順番の表示に変わる**（地図には番号と点線）。順番は位置と受付時間から**自動で提案**し、手で並べ替えもできる
5. **保存**: 順番の画面の下の「この予定を保存」→ 日付（初期値は次の土曜日、カレンダーから来たらその日）と名前 → カレンダーに印
6. **日が過ぎた予定は、実際に記録した寺社に ✓**（予定していた5社のうち4社回れた、が残る）
7. **収益化の線を引き直す**: 順番の自動提案は**無料**（無いと機能の核が欠ける）。**プラスは「予定をいくつでもカレンダーに入れる」**（無料は1つ）＋ 将来の本当の乗り換え時間

## 1. 何をするか

休日に何社か回るとき、寺社を選んで**ある日の予定**を作り、回る順番を決める。
移動は**電車＋徒歩**が中心（オーナー回答 2026-09-26）。

- 選び方は2つ: **行きたいリストから** / **地図で近くの寺社から**（両方から足せる）
- 回る順番に番号を付け、地図の上で**点線でつなぐ**
- 寺社と寺社のあいだ（区間）ごとに、**「この区間を Google マップで」**。押すとその1区間の**電車＋徒歩の道順**が Google マップで開く
  - Google マップは**電車の経路で複数の目的地を扱えない**（2026-09-26 確認）ので、まとめて渡さず区間ごとに渡す
- 区間の所要時間は**距離からの目安**（経路検索の API は使わない＝費用 0）
  - 直線距離 × 1.3 が 1.5km 以内 → 「徒歩 約N分」（分速80m）
  - それより遠い → 「電車などで移動 約N km」
- 各寺社に**受付時間**（あれば）を出す。回る順番の目安の時刻が受付の終わりを過ぎたら、朱で知らせる

## 2. 画面（試作 v1。§0 で置き換えた部分がある）

| #   | 画面               | 中身                                                                                                                                  |
| --- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| ①   | 予定の入口         | 地図タブの検索欄の右に「予定」。スポットのシートにも「予定に入れる」                                                                  |
| ②   | 寺社を選ぶ         | 上に地図（押すと追加）、下に「行きたい」の寺社（チェックで追加）。下に「選んだ寺社 N ・ 順番を決める」                                |

| ④   | 順番を自動で並べる | 近い順に並べ替える（出発地点から、最短に近い順）。**プラス**（課金をオンにするまでは誰でも使える）                                    |

## 3. 無料とプラス（収益化の設計 §8）

| 無料                                                      | プラス                                         |
| --------------------------------------------------------- | ---------------------------------------------- |
| 予定を1つ入れる・順番の自動提案・手で並べ替え・区間の目安 | 予定をいくつでもカレンダーに入れる             |
| 区間ごとに Google マップで開く                            | （将来）アプリの中での本当の乗り換え・所要時間 |

**課金をオンにするまでは、全部を誰でも使える**。コードには「プラスなら」の分かれ目だけ作る。

## 4. やらないこと（v1）

- アプリの中での本当の道順・乗り換え（案2。よく使われたらプラスで足す）
- 予定の共有・他人との同時編集
- 通知（前日にお知らせ など）
- 予定の寺社をまとめて記録する（その日の夜に「今日の予定の寺社を記録」は後で考える）
