# DESIGN.md — 御朱印さんぽ

Stitch の design system に渡す、このアプリの設計の正。
値は `src/theme/`（colors / typography / spacing / shadows）の実装そのまま。**ここと実装が食い違ったら実装が正**。

## 1. このアプリ

御朱印（神社・寺で授かる手書きの墨書と朱印）の**参拝記録**を、地図の上に貯めていくモバイルアプリ（iOS / Android・Expo + React Native）。

- コンセプト: **「集めるたび、地図があなたの旅になる。」**
- ユーザー: 20〜30代女性が中心。「SNS疲れしたが静かに記録したい」層
- ポジション: **SNSなし・広告なし・高速で美しい記録特化**。競合（ホトカミ等）は SNS 型で UI が過密。空席はこちら
- **紙の御朱印の代替は作らない**。デジタル化するのは「参拝の記録」であって御朱印そのものではない

### 画面（全14）とタブ

下タブは**4つ**。`地図 / 御朱印帳 / あゆみ / 設定`（中央 FAB は無い）。

| タブ     | 画面                                                                |
| -------- | ------------------------------------------------------------------- |
| 地図     | MapScreen（寺社ピン） → SpotDetail → Record → RecordComplete        |
| 御朱印帳 | GalleryScreen（御朱印のグリッド／蛇腹めくり） → StampDetail         |
| あゆみ   | CollectionScreen（集計・バッジ・巡礼チャレンジ） → PilgrimageDetail |
| 設定     | SettingsScreen / アカウント削除 / 規約                              |

他: Login / Onboarding / Search / Error。

## 2. 色

すべて `src/theme/colors.ts` の実値。**新しい色を発明しないこと。**

### ブランド（primary）

`50:#FFF7ED  100:#FFEDD5  200:#FED7AA  300:#FDBA74  400:#FB923C  500:#f27f0d  600:#EA580C  700:#C2410C`

- **primary.500 `#f27f0d` がブランド色**。アクセント・主ボタン・選択中タブ
- `#C2410C`（700）は濃い側。グラデーションの終端、文字色

### 地と文字

| 用途                                   | 色        |
| -------------------------------------- | --------- |
| ふつうの画面の地（フォーム等）         | `#FFFFFF` |
| カードを並べる画面の地（あゆみ・設定） | `#F2F2F7` |
| カード面                               | `#FFFFFF` |
| 罫線                                   | `#E5E7EB` |

### 都道府県の塗り（新規・地図可視化用）

訪問の濃さを3段で表す。**未訪問は `#E3E4E8`**（灰。「まだ」であって「無い」ではない）。

`1〜2枚:#FDBA74` → `3〜5枚:#f27f0d` → `6枚〜:#C2410C`、**いちばん新しい県は `#DC2626`**。

## 3. 文字

システムフォント（iOS = Hiragino Sans）。カスタムフォントは読み込んでいない。Stitch 上は **Noto Sans** で代替する。

| 役割      | size / weight / lineHeight |
| --------- | -------------------------- |
| h1        | 28 / 700 / 34              |
| h2        | 22 / 700 / 28              |
| h3        | 18 / 600 / 24              |
| body      | 16 / 400 / 24              |
| bodySmall | 14 / 400 / 20              |
| label     | 12 / 500 / 16              |
| caption   | 12 / 400 / 16              |
| button    | 16 / 600 / 24              |

数字を大きく見せる箇所（集計の「12」「34枚」）だけ 26〜34 / 900 相当まで上げてよい。

## 4. 余白・角丸・影

- 余白: `4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64`。画面の左右は **16**
- 角丸: `sm:4  md:8  lg:12  xl:16  2xl:20  3xl:24  full:9999`。**カードは 12〜16**。pill は chip とボタンのみ
- 影: 薄い。カード = `y1 / blur2 / 5%`〜`y2 / blur4 / 10%`。地図に浮かせるものだけ `y3 / blur6 / 22%`

## 5. 部品の作法

- **カード**: 白面 + 角丸12〜16 + 薄影。`#F2F2F7` の地の上に並べる
- **集計カード**: `#f27f0d → #C2410C` のグラデーション、文字は白
- **プログレスバー**: 高さ 6〜8、`full` 角丸、地 `#E5E7EB`、塗り `#f27f0d`
- **chip**: 12px・pill・淡い地（`#FFF7ED` など）に濃い文字
- **バッジ**: 円形のアイコン（絵文字可）。未獲得は不透明度を落とす。**鍵アイコンで塞がない**
- **アイコン**: Material Icons（`explore / menu-book / timeline / settings`）
- **画像**: 御朱印は縦長（3:4）。生成画像でそれらしい墨書と朱印を置く

## 6. 文言と態度

- **UI の文字はすべて日本語**。英語ラベルを混ぜない
- タブ名は `地図 / 御朱印帳 / あゆみ / 設定`。「コレクション」は旧称で**使わない**
- 参拝は信仰の対象。**「攻略」ではなく「記念」**の語彙で書く
- 数字より、その人が実際に行った場所と日付を主役にする
