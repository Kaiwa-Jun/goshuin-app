プライバシーポリシー

御朱印マップ

最終更新日: 2026年4月4日

1. はじめに

このプライバシーポリシーは、「御朱印マップ」（以下「本アプリ」）がユーザーの個人情報をどのように収集・利用・保護するかを説明するものです。 本アプリを利用することにより、ユーザーはこのプライバシーポリシーに同意したものとみなされます。本ポリシーをよくお読みいただき、同意いただける場合のみ本アプリをご利用ください。

2. 収集する情報

本アプリは以下の情報を収集します。 【アカウント情報】 Googleアカウントを通じた認証（Google OAuth）により、メールアドレス、表示名（ニックネーム）、プロフィール画像URLを取得します。これらはアカウント識別およびプロフィール表示に使用します。 【位置情報】 expo-location（精度: Accuracy.Balanced）を使用して、アプリ使用中のみ現在地情報を取得します。周辺の神社・寺院スポットの表示および地図上の現在地表示に使用します。

位置情報はサーバーに保存しません。端末上でのみ利用し、通信後は保持しません。

【カメラ・写真ライブラリ】 御朱印画像の撮影または写真ライブラリからの選択に使用します。選択された画像はJPEG形式（品質0.8）に変換してサーバーに保存されます。 【ユーザー入力データ】 訪問日、御朱印に関するメモ、御朱印の公開/非公開設定、御朱印帳情報、ウィッシュリスト（訪問したいスポットのリスト）など、ユーザーが本アプリに入力したデータを収集・保存します。

3. 情報の利用目的

収集した情報は以下の目的で利用します。 【御朱印記録の保存・表示】 ユーザーが記録した御朱印（画像・メモ・訪問日）をサーバーに保存し、アプリ上で閲覧・管理できるようにします。 【周辺スポットの表示】 端末上の位置情報を使用して、現在地周辺の神社・寺院スポットを地図上に表示します。 【AI情報抽出】 ユーザーが入力したメモテキストを、サーバー側の処理（Edge Function）を経由してAI（Claude API / Anthropic）に送信し、駐車場の有無・収容台数、受付時間、アクセス方法などの情報を自動抽出します。

メモテキストのみを送信し、画像やその他の個人情報は送信しません。

【御朱印の公開表示】 ユーザーが公開設定にした御朱印は、当該ユーザーの表示名およびプロフィール画像とともに他のユーザーに表示されます。

4. 情報の保存場所

収集した情報は、Supabase（Amazon Web Services ap-northeast-1 東京リージョン）のサーバーに保存されます。 御朱印画像はSupabase Storageに保存されます。 すべてのデータはHTTPS通信によって暗号化された状態で送受信されます。 位置情報のみサーバーには保存されず、端末上での処理にのみ使用されます。

5. 第三者提供

本アプリは以下の第三者とデータを共有する場合があります。 【Google LLC】 Googleアカウントによる認証（OAuth）のため、Googleの認証サービスを利用します。Googleのプライバシーポリシーが適用されます。 【Supabase Inc.】 データベース、ストレージ、認証基盤としてSupabaseのサービスを利用しています。ユーザーデータはSupabaseのサーバーに保存されます。 【Anthropic】 メモテキストのAI情報抽出を目的として、ユーザーが入力したメモテキストのみをAnthropicのClaude APIに送信します。画像や個人を特定できる情報（氏名・メールアドレス等）は送信しません。AnthropicのプライバシーポリシーはAnthropicの公式サイトをご参照ください。 【他のユーザー】 御朱印を公開設定にした場合、当該御朱印の画像・メモ・訪問日・スポット情報が、表示名およびプロフィール画像とともに他のユーザーに表示されます。 上記以外の第三者に個人情報を提供することはありません（法令に基づく場合を除く）。

6. データセキュリティ

本アプリは以下のセキュリティ対策を講じています。 【Row Level Security（RLS）】 SupabaseのRLS機能により、ユーザーは自分自身のデータのみにアクセスできるよう制御しています。他のユーザーのプライベートデータへの不正アクセスを防止します。 【HTTPS通信の暗号化】 すべての通信はHTTPSプロトコルによって暗号化されています。 ただし、インターネット上での完全なセキュリティを保証することはできません。ご了承ください。

7. データの保持と削除

アカウントを削除した場合、以下のデータが削除されます。 ・御朱印記録（画像・メモ・訪問日・スポット情報） ・御朱印帳情報 ・ウィッシュリスト ・プロフィール情報（表示名・プロフィール画像URL） ただし、複数ユーザーのメモから自動抽出された情報（特定のスポットの駐車場情報・アクセス情報など）は、個人を特定できない形で匿名化・集約されているため、サービス品質向上を目的として保持される場合があります。 アカウント削除後はデータの復元ができません。

8. ユーザーの権利

ユーザーは以下の権利を有します。 【データへのアクセス】 本アプリ内で自身が記録した御朱印データを閲覧・確認することができます。 【公開/非公開の設定変更】 投稿した御朱印の公開設定はいつでも変更できます。非公開に変更した場合、他のユーザーからの閲覧ができなくなります。 【データの削除】 アカウントを削除することにより、ご自身のデータを削除することができます。削除はアプリの設定画面から行えます。 ご不明な点やデータに関するお問い合わせは、本ポリシー末尾の連絡先までご連絡ください。

9. Cookieおよびトラッキング

本アプリは、Cookieや行動トラッキング技術を使用しません。ユーザーの行動パターンの追跡や、広告目的でのデータ収集は行いません。

10. 子どものプライバシー

本アプリは13歳未満の子どもを対象としていません。13歳未満の方の個人情報を意図的に収集することはありません。 保護者の方が、お子様が13歳未満であるにもかかわらず本アプリを使用していることに気づいた場合は、下記の連絡先までお問い合わせください。

11. ポリシーの変更

本プライバシーポリシーは、法令の改正やサービスの変更に伴い更新されることがあります。 重要な変更がある場合は、アプリ内での通知またはその他の適切な方法でユーザーにお知らせします。変更後のポリシーに同意できない場合は、本アプリの利用を停止し、アカウントを削除してください。 継続して本アプリを利用することで、更新後のポリシーに同意したものとみなされます。
