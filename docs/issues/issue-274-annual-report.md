# Issue #274: 年報「{年}年のふりかえり」: 一年の参拝を動くふりかえりで見せる

## 概要

その年（日本時間の 1月1日〜12月31日の `visited_at`）に記録した御朱印から、本人の一年の参拝を **8シーン・約40秒の動くふりかえり**にして見せる。画面に出す呼び方は「{年}年のふりかえり」、仕様書とコードの中の呼び名は「年報」（annual report）。

- 見た目と動きは **動きの試作 v1（正）** のとおり。明るい案（和紙の地と朱）・音なし。シーンの長さ・各要素の遅延と長さは試作の `SCENES[].ms` と `tween(delay, duration)` の値（D-9）。データが足りないシーンは飛ばす（D-8）
- 自動で進む。押している間は止まる。左 1/3 を押すと前のシーンの頭、それ以外で次。✕ で閉じる。視差効果を減らす がオンなら各シーンの最後の形をすぐ出し、自動では進まず、押して進める（D-11・D-12）
- 入口は2つだけ: **① 12月（日本時間）にメインのタブが出たとき1回だけの自動再生**（ログイン済み・その年の記録1件以上・その年とアカウントの印が無いとき。D-17）/ **② あゆみ**（12月はいちばん上のカード、1月からは下の方の欄。D-16）。アプリの中のお知らせ・通知は出さない
- 開発用（`__DEV__` だけ）: 設定の「開発用」に「年報を見る」「年報の見本を見る（記録が2枚）」「12月として自動再生を試す」（D-19）
- **JS だけで作る**（`package.json` の差分なし）。動きは RN の `Animated`（`useNativeDriver: false`）と `react-native-svg`。DB・Edge Function の変更なし
- 過ぎた年をプラスにする分かれ目は**この Issue では作らない**（D-22。`BILLING_ENABLED = false` の間は誰でも見られるので、作っても作らなくても振る舞いは同じ）
- 共有（画像の書き出し・共有シート）・動画の書き出し・音・通知は作らない（要件 §0-5・6・11、§5、§9）

## 注意事項

- **動きは1本の時計から作る**（D-11）。要素ごとに `Animated.timing` や `Animated.delay` を持たせると、押して止めたときに止まらない要素が出る。`SaveMapReveal.tsx` のコメントにある「`Animated.delay` はイージングを渡せない」とも合わせて、`interpolate` の `easing` を使う
- **シーンの部品は `clock` を props で受ける**（テストで `setValue` できるように）。画面の外れ（✕・アンマウント）では時計の `stopAnimation` と listener の `removeAllListeners`、「止まっています」のタイマーの `clearTimeout` を必ず行う（#209 の `SaveMapReveal` で、止め忘れたタイマーが別のテストの最中に発火して壊れた）
- 地図の重ねの県は `JAPAN_PREFECTURE_PATHS` の形をそのまま使う。47県すべてに重ねを置かない（足を運んだ県だけ。描く数を減らす）
- 数え上げの listener は、表示の数が変わったときだけ `setState` する（毎フレーム描き直さない）
- **数え上げの最初の表示は、時計の今の値から計算する**（listener だけに頼らない）。視差効果を減らす では、シーンが listener を付ける前に時計が `FINAL_CLOCK_MS` に置かれていることがあり、listener 頼みだと「0」のまま残る（AC-33）
- **締め（`SCENE_MS.end = 0`）のバーは `interpolate` を作らず、固定で 100% にする**（`inputRange: [0, 0]` は 0 で割って NaN になる）
- `useCollectionStats` の `annualReports` は、今の `visitLog` から `useMemo` で作る。`annualReportNow()` はレンダーのたびに読む（開発用で 12月にしたあと、あゆみに戻ると出るように）
- `fetchAnnualReportSource` は本人の全件を取る。Supabase の既定の上限（1000行）を超える人は切れる（今の `fetchVisitLog` と同じ。リスク）
- 見本のデータ（D-20）は開発用と Web の確認のためのもの。本番の画面の分岐に `sample` を使わない（`sample` の params があるときだけ）

- **過ぎた年のプラスの分かれ目（#270 H-7 への申し送り）**: 要件 §6 は「過ぎた年はプラス・コードには分かれ目だけ作る」だが、この Issue では作らない（D-22）。**スイッチ（`BILLING_ENABLED`）を入れる Issue で、① あゆみの「ふりかえり」の欄の過ぎた年を押したときの分かれ目（`usePlus` を使える場所に `CollectionScreen` を足すか、年報の画面の側で分けるか）② 見られないときの案内の形（プラスの画面へ行くか・シートか）を決めて足す**。スイッチを入れない限り、過ぎた年も誰でも見られる（要件どおり）。2027年1月以降にスイッチを入れる場合は、入れる前に必ず足す

- **`presentation: 'fullScreenModal'` と `animation: 'none'`**（D-13）: iOS で下から上がる動きが消えるかは未確認。UI-17 で見て、消えなければ D-13 の代わりの設定にする
- **`DevSettings.reload()`**（D-19）: Expo の dev client のローカルの Debug ビルドで読み込み直せるかは未確認。できなければ、開発用のキーを書いたあと Metro の `r` で読み込み直す手順にして progress.md に書く（キーの読み方は同じ）
- **Jest は `TZ=Asia/Tokyo` で走る**ので、端末のタイムゾーンが日本でない人の不具合はテストでは見つからない。瞬間（`…Z`）で入力を固定する AC-1・51 と、ローカルの getter を使わない Q-7 で防ぐ
- **2026年はほとんどの人が「使い始めた年」**: D-5 のとおり「はじめて足を運んだ県」が出ないので、印象のシーンは「同じ寺社に2日以上」の人だけに出る。2026年の12月は印象のシーンが飛ぶ人が多い見込み（H-1 で確認）

- **試作・要件と違えたところ**（オーナーの確認があるとよい）: ① 印のラベルは `Badge.name`（試作は短い名前）D-6 ② 達成のシーンを満願だけでも出す D-8 ③ 県・印が多い人は間隔を詰める D-9 ④ 過ぎた年の見出し D-15 ⑤ あゆみの欄の見出し「ふりかえり」D-16 ⑥ 県が全国に広がった人は寄らない D-10 ⑦ 写真は一年から散らして16枚 D-4 ⑧ 印象のカードが1枚のときの遅延を 300ms にした D-9 の表
