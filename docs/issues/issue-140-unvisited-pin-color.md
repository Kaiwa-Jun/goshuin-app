# Issue #140: 未訪問ピンを淡いブランド色にする（D-5 / 監査 A-9）

- **規模**: S
- **決定の出典**: `docs/design/ux-audit-2026-08.md`「D-5 の決定」（2026-08-11）
- **制約の出典**: `docs/issues/issue-099-map-clustering.md` 追補1〜4

## 1. 目的

未訪問ピンの塗りをグレーから**淡いブランド色1色**に変え、地図上で「まだ行っていない場所」が行き先候補として読めるようにする。

**形・サイズ・要素・再描画の性質は一切変えない。** 変えるのは色トークンの値ひとつだけ。

## 2. 背景と現状

現行値は `colors.pin.unvisited = '#9CA3AF'`（`src/theme/colors.ts:50`）。これは `colors.gray[400]` と**同じ hex** だが別トークンであり、両者は独立している。

色を消費しているのは2箇所で、どちらも**トークン参照なので変更不要**（本 Issue では動作確認のみ）:

| 消費側                                   | 行    | 内容                                                      |
| ---------------------------------------- | ----- | --------------------------------------------------------- |
| `src/screens/MapScreen.tsx`              | 46-55 | `getPinColor()` — 訪問済み → 行きたい → 未訪問 の順に解決 |
| `src/screens/PilgrimageDetailScreen.tsx` | 88-93 | `getPinColor()` — 訪問済み → 未訪問（行きたいの分岐なし） |

描画は `src/components/common/SpotMarker.tsx` で、受け取った `color` を `pinHead` の `backgroundColor` と `pinTail` の `borderTopColor` に流している。

## 3. 決定内容（D-5・決定済み。ここでは再検討しない）

| 項目          | 決定                                                             |
| ------------- | ---------------------------------------------------------------- |
| 未訪問の塗り  | 淡いブランド色1色（`primary` 系の淡い段）                        |
| 神社/寺の区別 | 未訪問では**つけない**（1色）。訪問済みの赤/紫の色分けは**維持** |
| 形・サイズ    | **変えない**                                                     |

## 4. 具体値の選定: `primary[200]` (`#FED7AA`)

D-5 は「`primary` 系の淡い段。具体値は契約書で確定する」としていた。**`primary[200]` = `#FED7AA` を採る。**

### なぜ `primary[300]`（`#FDBA74`）ではないのか — 行きたいピンとの衝突

⚠️ **これが本件で唯一の非自明な判断。** `colors.pin.wishlisted` は `#F59E0B`（アンバー）で、**未訪問を橙系にすると行きたいピンと同系色になる**。

| トークン         | hex       | rgb           | 概略の明度         |
| ---------------- | --------- | ------------- | ------------------ |
| `pin.wishlisted` | `#F59E0B` | 245, 158, 11  | 中（L\* ≈ 71）     |
| `primary[300]`   | `#FDBA74` | 253, 186, 116 | やや高（L\* ≈ 80） |
| `primary[200]`   | `#FED7AA` | 254, 215, 170 | 高（L\* ≈ 88）     |

`primary[300]` は色相も明度も `wishlisted` に近く、**地図上で 24px の円として並ぶと「行きたい」と「未訪問」が判別できなくなる**恐れがある。`primary[200]` なら色相は同系のまま明度差が十分にあり、「淡い＝未訪問 / 濃い＝行きたい」という自然な階調として読める。

D-5 が明記した「**淡さの度合いで調整する**」の調整結果がこれ。

### 訪問済みが埋もれないか

D-5 が承知の上で受け入れたトレードオフ（未訪問に色を付けると訪問済みが相対的に埋もれる）に対しては、`primary[200]` の彩度の低さが効く。訪問済みの赤 `#EF4444` / 紫 `#A855F7` は彩度が高く、淡いピーチの中では引き続き主役として立つ。

**ただしこれは机上の判断なので、実地の見え方はユーザーの目視で確定する**（§8 参照）。
