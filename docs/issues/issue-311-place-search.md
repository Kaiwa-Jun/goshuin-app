# Issue #311: 地図の検索で、地名・駅名から探して、その地域のピンを地図で見せる（エンターでも開く）

## 概要

地図の検索画面（地図タブ → 上の検索バー）は、いま寺社の名前に打った文字が含まれるかだけを見ている（`useSearchScreen` の `name.includes`）。これを次のようにする。

1. **第1段（端末の中で探す）**: 名前に加えて、寺社の**住所と県**でも当てる。「横浜」で横浜市の寺社が出る。地名として当たったときは、一覧に「「横浜」のあたりを地図で見る」の行（以下「場所の行」）を出す
2. **第2段（外に問い合わせる）**: 名前にも住所にも1件も当たらない言葉（駅名・名所。例「渋谷駅」「スカイツリー」「東京タワー」）だけ、**国土地理院の地名検索**で位置を引き、そこから半径 2km の寺社と場所の行を出す
3. **エンター**: キーボードの「検索」キーは、**一覧のいちばん上の行を押したのと同じ**。寺社の行なら今と同じく地図に移ってピンを選び、シートを出す。場所の行なら地図をその地域に寄せ、その地域の寺社を**団子にせず・間引かずに全部**ピンで出す。0 件なら何もしない

1.2.0（審査中。出し直す前提）に入れる。見た目が新しくなる所（場所の行・寄せた地図）は、最初のスライス S0 で HTML の動く試作を作ってオーナーに選んでもらう。

### 流れ

```
検索欄に入力 ─(300ms)─> 第1段: 名前・住所・県で当てる（端末の中）
   ├ 1件以上 ──> 一覧 = 並べ方（D-5）: [場所の行…][名前の寺社…][地名だけの寺社…] など
   └ 0件・2文字以上 ──> 第2段: 国土地理院（D-7〜D-9）
         ├ 場所あり ──> 一覧 = [場所の行（≤3）…][その近くの寺社…] ＋「出典：国土地理院」
         └ なし・失敗 ──>「見つかりませんでした」（今のまま）

エンター ──> いま入っている言葉で一覧を作り直し、いちばん上の行（第2段が要るなら答えを待つ）
   ├ 寺社の行 ──> 押したのと同じ: addHistory → navigate('Map', { focusSpotId })
   ├ 場所の行 ──> navigate('Map', { focusRegion })（履歴に残さない）
   └ なし ──────> 何もしない（キーボードも閉じない）

地図（focusRegion）──> シートを閉じる・検索バーに label・fitBounds（点なら flyTo）
                     ・その地域の寺社を goshuin-pinned に入れる（団子にしない・間引かない）
   × ／ 寺社の focusSpotId ／ focusRegion が無くなる ──> 地域の表示を消す（カメラは動かさない）
```

### 設計上の決定（この契約で確定する）

| #    | 決定                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | 理由                                                                                                                                                                                                                                                 |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-1  | **言葉のそろえ方** `normalizeQuery(text)` = `text.normalize('NFKC').replace(/\s+/g, '').toLowerCase()`。名前・住所・県・国土地理院の title と比べるときは、どちらもこの形にしてから比べる                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | 全角・半角と空白で当たり外れが変わらないように                                                                                                                                                                                                       |
| D-2  | **名前で当てる**: `normalizeQuery(spot.name).includes(q)`（1 文字から当たる。今と同じ）。名前で当たった寺社のうち、名前が**そのまま一致**する寺社（`normalizeSpotName(spot.name) === normalizeSpotName(入れた言葉)`）を先頭に置く（一致どうし・それ以外どうしは入力の順＝近い順）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | エンターで「明治神宮」と打てば明治神宮が開く（Issue）                                                                                                                                                                                                |
| D-3  | **地名で当てる** `isAreaMatch(spot, q)`: q が **2 文字以上**（`MIN_AREA_QUERY_LENGTH = 2`）のときだけ。`pref = spot.prefecture ?? 住所の先頭の県（PREFECTURE）`、`rest = normalizeQuery(住所)` から先頭の県を落としたもの。次のどれかで当たり: ① `q === pref` または `q === pref から末尾の「都」「府」「県」を1字落としたもの`（「東京」「京都」「宮城」。北海道は「北海道」だけ）② `rest.includes(q)` ③ q が 47 の県名のどれかで始まるとき、その県が `pref` と同じで、残りが空でなく `rest` に含まれる（「神奈川県横浜市」）。住所も県も無い寺社は当たらない                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | 住所の全体に `includes` すると「京都」が「東京都…」に当たる（seed で 139 件当たり、多くが東京都）。県は丸ごとか「都府県」を落とした形でだけ当てる。1 文字（「中」）で住所に当てると何にでも当たる                                                    |
| D-4  | **場所の行（第1段）**: 地名で当たった寺社（神社・寺院の絞り込みのあと）を**県ごと**にまとめ、まとまり1つに行を1つ作る（県の無い寺社は県 `null` のまとまり）。行 = `{ kind: 'place', key: 'area:' + (県 ??
