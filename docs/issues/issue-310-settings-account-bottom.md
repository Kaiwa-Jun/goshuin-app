# Issue #310: 設定のログアウトとアカウント削除を画面の一番下へ移す

## 概要

設定画面のログアウトとアカウントの削除は、今は一番上の「アカウント」の枠の中、名前とメールのすぐ下にある。取り消せない操作なので、画面の一番下に移し、削除を最後にする（オーナー 2026-10-04「とくにアカウント削除は一番下がいい」）。1.2.0 の出し直しに入れる。

## 設計上の決定

| #   | 決定                                                                                                                                                                               | 理由                                                                                            |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| D-1 | 一番上の「アカウント」の枠には、名前とメールだけを残す。ログインしていないときの「ログイン」は今のまま、この枠に置く                                                               | ログインはしたい操作なので上でよい                                                              |
| D-2 | ログアウトとアカウントを削除は、「アプリ情報」のさらに下に、見出しの無い独立した枠（`settings-section-account-actions`）として置く。ログインしているときだけ出す                   | iOS の設定アプリなどと同じく、取り消せない操作は最後。見出しを付けると「アカウント」が2つになる |
| D-3 | 枠の中は ログアウト → アカウントを削除 の順。削除が画面の最後の行                                                                                                                  | オーナーの要望                                                                                  |
| D-4 | 押したときの動き（`handleLogout`・`handleDeleteAccount`・失敗のときの Alert）、行の見た目（赤い文字・アイコン）、`delete-account-row` の testID は変えない                         | 動きは #134 のまま                                                                              |
| D-5 | 枠の余白は、ほかのセクションと同じ `styles.section`（gap で組み、個別の margin を持たない）                                                                                        | 「セクションの余白」のテストの決まり                                                            |
| D-6 | 審査メモ（`scripts/asc-review.mjs` の `notesText`）の削除の道順を「"設定" tab -> scroll to the bottom -> "アカウントを削除"」にする。送り直すのは 1.2.0 を出し直すとき（リーダー） | 審査の人が迷わないように                                                                        |
