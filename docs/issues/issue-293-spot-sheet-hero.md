# Issue #293: 地図のピンのシートの上部に「場所の顔」の帯を足す（第1段: 写真なし・空押しの印と自分の御朱印）

## 概要

地図のピン（または検索）から出るシート（`SpotBottomSheet`）は文字の情報だけで、場所の印象が薄い。オーナーの要望で、シートの上に横長の帯を置き、その上に名前・種別・訪問済みの札を重ねる。第1段は写真を使わない。

1. **帯（案B）**: 半分のときは細い帯 80pt、大きく開くと 208pt。ドラッグに合わせて伸び縮みし、放すと今のシートと同じ spring で落ち着く。帯は 208pt で描いたまま動かさず、名前から下の中身を最大 128pt 持ち上げて帯の下の端に重ねる
2. **行っていない寺社（案い 空押し）**: 和紙の地に、その寺社の印（神社は鳥居・お寺はお堂）を、帯からはみ出す大きさで色を付けずに型だけ押す
3. **行った寺社**: 空押しの印の上に薄い朱の跡（不透明度 0.2）、右に自分の御朱印のページ。回数の分だけ後ろに紙が重なる（3枚まで）
4. **記録した瞬間**: 印に朱が乗り（0.5秒）、自分のページが出る（0.25秒）
5. 4 を実際に見せるため、地図に戻ったときに訪問済みとシートの記録を取り直す（今は取り直していない。D-11）

新しいネイティブの部品は足さない（`package.json` の差分なし）。View・`expo-linear-gradient`・`react-native-svg`・RN の `Animated` で作る。EAS のビルドは使わない。

### 画面仕様（値は試作のまま）

#### 地図 → ピン（または検索結果）→ シートが半分で出る

- シートの上の端から 80 までが帯。和紙の地に細い縦の筋。つまみ（灰色の小さな棒）は今と同じ位置で帯の上に乗る
- 名前の行（名前・神社 / 寺院・訪問済みの札・行きたいの印）は帯の下の端に重なる（上の端から 50）。名前の行の少し上から帯が白くぼけていき、名前の下からは白
- **行っていない寺社**: 帯の右寄りに、帯からはみ出す大きな印の型（神社は鳥居・お寺はお堂）。色は付けず、紙に型を押したような凹み（左上に薄い陰・右下に光）。半分のときは鳥居の笠木・お堂の屋根が帯を横切って見える
- **行った寺社**: 同じ印が薄い朱（不透明度 0.2）で残り、右に自分の御朱印のページ（いちばん新しい記録の写真）。2回以上なら後ろに紙が1〜2枚、少し傾いて重なる。半分のときはページの下の方がシートの白に隠れ、挟まっているように見える。写真が届くまでは和紙の紙
- その下は今と同じ並び（住所・受付・写真の帯・限定御朱印の見出し）とフッター（行きたい・記録する）。シートは今より 30 高い

#### 大きく開く（つまみ・帯を押す / 上へ引く）

- 帯が 208 まで伸び、名前から下がそのぶん下がる。印は大きく（250 → 300）なって少し下がり、ページは大きく（62 → 120 幅）なって左下へ降りてくる。ドラッグ中は指に合わせて連続に動き、放すと今のシートと同じ spring で落ち着く
- 帯を押すか、帯・つまみを下へ引くと半分に戻る。中身を下へ引くとスクロール（#253 のまま）。スクロールしても帯は上に残り、中身は帯の下にもぐる

#### 記録した瞬間（行っていない寺社で「記録する」→ 記録 → 「地図に戻る」）

- 地図に戻ると、訪問済みとシートの記録を取り直す。届いたら、ピンが朱になり、札「訪問済み」が出て、帯の印に上から朱が乗る（1.3 倍から押し込まれ、少し沈んで戻る。0.5秒）
- 続けて、朱が薄い跡（0.2）になり、型の凹みが消え、右に自分の御朱印のページが出る（0.25秒）。下の写真の帯にも記録の写真が入る（今のまま）
- 2回目の記録（もう行った寺社）では動かない。束が1枚増えるだけ

#### 視差効果を減らす がオン

- 記録した瞬間は動かず、次の描画で朱の跡とページが出ている。帯の伸び縮みはシートの位置のまま（シートの動きは今のまま）

## テスト方針

- **値は純関数で縛る**（`spotHeroMotion.test.ts`）。補間は `new Animated.Value()` から作り、`setValue()` のあと `__getValue()` で読む（#276 と同じ）。数の比較は特に書かない限り小数3桁（位置・倍率）か 1e-6（曲線・不透明度）

## オーナー・リーダーに決めてもらうこと

2. **訪問済みの札の出方**（おすすめ: この Issue では今のまま）。試作は印を捺し終えた 0.5秒後に札がふわっと出る。この契約では取り直しが届いた瞬間に札が出る（動きなし。印の朱と同時）
3. **大きく開いてスクロールしたとき、帯は上に残る**（おすすめ: 残す）。帯がつまみと同じ「つかむ所」になり、試作の「帯を押す・引くと開閉」がそのまま効く。代わりに、大きく開いたときの中身の見える高さが今より 132 小さく、スクロールした中身は帯の下の端で切れる。帯ごとスクロールで上へ流す形にもできる（その場合、大きく開いて帯を引いてもシートは動かずスクロールになる）

## 実装で分かったこと（2026-09-28・S6 のあとリーダーが決めた）

1. **半分の高さの上限を 380 → 410 にした**: iPhone 16 でも、受付2行・写真の帯・限定御朱印の見出しのある京都の神社で半分の高さが上限 380 に掛かり、見出しが約 15〜20pt フッターに隠れた（帯で 30 高くなったため）。増えた 30 を上限に足して打ち消す。画面の 0.6 の上限はそのまま
2. **UI-8 の「大きくでスクロールしたまま中身の上を下へ引くと、シートが半分まで下がる」は前から**: 変更前の版（develop e3e2f64）でも同じ swipe でシートが下がった（ScrollView はネイティブのスクロールが始まってから responder を取るので、先に縦 8 を超えた動きでシートの PanResponder が取る）。#253 D-18 とは違うが、この Issue では直さない。大きくのときつまみが検索バーの下に重なって押せないのも、変更前の版から

## リスク・不確実な点／申し送り

- **ルートのスタックから戻ったときのフォーカス**: 記録の完了画面の「地図に戻る」（`popTo('MainTabs', …)`）で、入れ子の地図の画面に `focus` が届く前提（`useFocusEffect` の決まり）。UI-14 で見る。届かなければ瞬間は出ない（タブを行き来すると出る）
- **絞り込み「未訪問」のとき**: 記録して戻ると、その寺社は「未訪問」の地図から消えるので、`MapScreen` がシートを閉じる（今の決まり）。瞬間は見えない
- **レビュー依頼**（#288）: 地図に戻って 1.5秒後に呼ぶ。取り直しが遅いと、瞬間の途中でシステムの依頼が重なることがある
- **半分の高さが 30 高くなる**: 上限は 410 にして打ち消した（「実装で分かったこと」の1）。iPhone SE（半分の上限 371。410 にしても変わらない）で、受付・写真の帯・限定御朱印の見出しが全部ある寺社は上限に掛かり、見出しの下の端がフッターに少し隠れうる（概算 5pt）。UI-12 で見て、隠れたら記録して止める
- **帯が上に残る**: 大きく開いたときのスクロールの見える高さが 132 小さい（「決めてもらうこと」の3）
- **印の縁**: Seal と同じ 100 × 100 の図形を 250〜300pt に広げるので、手彫りの揺れが大きく見える（試作の申し送り）。UI-13 のスクリーンショットでオーナーに見てもらう
- **行った寺社を開いた直後**: 自分の記録が届くまで、表の紙は和紙・束は1枚。届いたら枚数分に増え、写真が出る（動きなし）
- **取り直しの回数**: 地図・予定・巡礼の画面に戻るたびに、訪問済み（1本）とシートの記録（シートが開いていれば1本）を取る。軽い問い合わせだが、回数は増える
- **Web の値の読み方**は RN Web が transform・opacity を要素の `style` に書くことに依存する（#276 と同じ）
- **Android と C++ の Animated の実装で、補間の補間（`open` から `lift`・rect）を確かめていない**（iOS は #253 のフッターで同じ形が動いている）
